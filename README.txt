DIGITAL MARKETING PORTFOLIO

Open index.html to start the website.

Structure:
- index.html — Home
- about.html — About Me
- services.html — Services
- portfolio.html — Portfolio
- blog.html — Blog
- contact.html — Contact
- css/style.css — shared styling
- js/script.js — shared interactions

Profile photo:

images/profile/profile.jpg

The service visuals are original CSS-based abstract visuals, so no random copyrighted stock photos are required.

The canonical URLs use https://example.com as a placeholder. Change them to your real domain before publishing.

The contact form performs client-side validation only; it has no backend, as requested.
